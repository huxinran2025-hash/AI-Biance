## 问题汇总

### 警告问题（WARNING）- 3天内处理

#### WARNING-008: ExchangeRiskWatcher 使用 window.setInterval（Node.js兼容性问题）

**严重程度**：WARNING  
**问题类型**：配置错误 / 环境兼容性  
**影响范围**：模块级（ExchangeRiskWatcher）  
**优先级**：P1

**问题描述**：
- **位置**：`backend/exchangeRiskWatcher.ts:77`
- **代码**：
```typescript
this.intervalId = window.setInterval(() => this.pollAllSources(), this.POLL_INTERVAL_MS);
```

- **问题**：
  - `ExchangeRiskWatcherService` 在 `start()` 方法中使用了 `window.setInterval`
  - 虽然 `backend/` 目录下的代码主要在浏览器环境中运行，但这是一个潜在的兼容性问题
  - 如果未来需要在Node.js环境中运行此服务，会导致运行时错误
  - 我们已经修复了 `window.dispatchEvent` 的问题，但遗漏了 `window.setInterval`

**影响分析**：
- **当前影响**：无（代码在浏览器环境中运行正常）
- **潜在影响**：
  - 如果代码迁移到Node.js环境，会导致运行时错误
  - 代码风格不一致（部分使用EventEmitter，部分使用window API）

**修复建议**：
- **方案A（推荐）**：使用环境检测，在浏览器环境使用 `window.setInterval`，在Node.js环境使用 `setInterval`
- **方案B**：统一使用Node.js的 `setInterval`（浏览器环境也支持）

**修复代码示例**：
```typescript
// 修复方案A：环境检测
public start(): void {
    if (this.intervalId) return;
    
    auditService.logInfo('Starting ExchangeRiskWatcherService polling...');
    
    // 环境检测：浏览器使用window.setInterval，Node.js使用setInterval
    const setIntervalFn = typeof window !== 'undefined' ? window.setInterval : setInterval;
    this.intervalId = setIntervalFn(() => this.pollAllSources(), this.POLL_INTERVAL_MS);
    
    // 立即执行一次检查
    this.pollAllSources();
}

public stop(): void {
    if (this.intervalId) {
        auditService.logInfo('Stopping ExchangeRiskWatcherService...');
        
        // 环境检测：浏览器使用window.clearInterval，Node.js使用clearInterval
        const clearIntervalFn = typeof window !== 'undefined' ? window.clearInterval : clearInterval;
        clearIntervalFn(this.intervalId);
        this.intervalId = null;
    }
}
```

**修复位置**：
- `backend/exchangeRiskWatcher.ts:77` - `start()` 方法
- `backend/exchangeRiskWatcher.ts:82` - `stop()` 方法（也需要检查）
